## Аутентификация

## Эндпоинты

### POST /api/login
- **Описание:** Авторизация пользователя.
- **Вход:** JSON `{ username, password }`
- **Выход:** 200 OK `{ ok: true, username, role, name }`
- **Ошибки:** 401 — неверный логин/пароль

### POST /api/logout
- **Описание:** Выход из системы.
- **Выход:** 200 OK

### GET /api/me
- **Описание:** Информация о текущем пользователе.
- **Выход:** 200 OK — данные пользователя
- **Ошибки:** 401 — не авторизован

---

### GET /api/pvz
- **Описание:** Получение списка ПВЗ.
- **Вход:** query params (фильтры по региону, типу и т.д.)
- **Выход:** 200 OK с телом в формате JSON.

### GET /api/pvz/{pvz_id}
- **Описание:** Детальная информация о ПВЗ и его расписании.
- **Параметры:** `pvz_id` (path, integer)
- **Выход:** 200 OK — данные ПВЗ + расписание
- **Ошибки:** 404 — ПВЗ не найден

---

### GET /api/operations
- **Описание:** Получение списка операций с фильтрацией и пагинацией.
- **Доступ:** `@login_required` (все роли; оператор видит только свои, супервайзер — свой регион, аналитик — все)
- **Query-параметры:**

| Параметр       | Тип     | Обязательный | Описание                                     |
|----------------|---------|--------------|----------------------------------------------|
| `pvz_id`       | integer | Нет          | Фильтр по ПВЗ                                |
| `type`         | string  | Нет          | Фильтр по типу: `in`, `out`, `return`        |
| `date_from`    | date    | Нет          | Начало периода (YYYY-MM-DD)                  |
| `date_to`      | date    | Нет          | Конец периода (YYYY-MM-DD)                   |
| `product_name` | string  | Нет          | 🔎 **НОВЫЙ** — LIKE-поиск по названию товара |
| `weight_min`   | number  | Нет          | 🔎 **НОВЫЙ** — минимальный вес (кг), ≥ 0     |
| `weight_max`   | number  | Нет          | 🔎 **НОВЫЙ** — максимальный вес (кг), ≥ 0    |
| `limit`        | integer | Нет          | Пагинация (по умолчанию 200)                 |
| `offset`       | integer | Нет          | Смещение (по умолчанию 0)                    |

- **Выход:** 200 OK
```json
{
  "total": 1500,
  "limit": 200,
  "offset": 0,
  "data": [
    {
      "op_id": 1001,
      "pvz_id": 2,
      "address": "ул. Ленина, 10, Москва",
      "ts": "2025-03-10 14:30:00",
      "type": "out",
      "product_name": "Смартфон",
      "weight_kg": 0.35
    }
  ]
}
```

### POST /api/operations
- **Описание:** Создание новой операции.
- **Доступ:** `@role_required("operator", "analyst")`
- **Вход:** JSON

| Поле          | Тип     | Обязательный | Описание                                              |
|---------------|---------|--------------|-------------------------------------------------------|
| `pvz_id`      | integer | Да           | Идентификатор ПВЗ                                     |
| `ts`          | string  | Да           | Метка времени, формат `YYYY-MM-DD HH:MM:SS`          |
| `type`        | string  | Да           | Тип: `in`, `out`, `return`                            |
| `product_name`| string  | Нет          | 🆕 **НОВЫЙ** — наименование товара (maxlen=200; при пустоте → «Не указан») |
| `weight_kg`   | number  | Нет          | 🆕 **НОВЫЙ** — вес товара в кг (0–1000; по умолчанию 0.0) |

- **Выход:** 201 Created `{ "ok": true, "op_id": 1042 }`
- **Ошибки:**
  - 400 — ошибка валидации (неверный тип, ПВЗ закрыт, неверный формат ts, product_name > 200 симв., weight_kg вне диапазона)
  - 403 — оператор пытается создать операцию для чужого ПВЗ

### GET /api/report/load
- **Описание:** Генерация отчёта о загрузке ПВЗ с расширенными метриками.
- **Доступ:** `@login_required`
- **Query-параметры:**

| Параметр   | Тип     | Обязательный | Описание                    |
|------------|---------|--------------|------------------------------|
| `pvz_id`   | integer | Нет          | Фильтр по ПВЗ               |
| `region`   | string  | Нет          | Фильтр по региону           |
| `type`     | string  | Нет          | Фильтр по типу операции     |
| `date_from`| date    | Нет          | Начало периода              |
| `date_to`  | date    | Нет          | Конец периода               |

- **Выход:** 200 OK
```json
{
  "data": [
    {
      "pvz_id": 1,
      "address": "ул. Ленина, 10, Москва",
      "region": "Центральный",
      "date": "2025-03-10",
      "hour": 12,
      "ops_per_hour": 45,
      "ops_in": 12,
      "ops_out": 28,
      "ops_return": 5,
      "capacity_per_hour": 50,
      "load": 0.9,
      "load_pct": 90.0,
      "overloaded": false,
      "total_weight": 35.75,
      "avg_weight": 0.79
    }
  ],
  "kpi": {
    "avg_load_pct": 72.5,
    "avg_peak_load_pct": 95.3,
    "overload_share_pct": 18.2,
    "total_intervals": 1200,
    "total_overloaded": 218
  }
}
```

- **Новые поля ответа (по сравнению с v1.0):**

| Поле          | Тип     | Описание                                    |
|---------------|---------|----------------------------------------------|
| `ops_in`      | integer | 🆕 Количество приёмок за интервал            |
| `ops_out`     | integer | 🆕 Количество выдач за интервал              |
| `ops_return`  | integer | 🆕 Количество возвратов за интервал         |
| `total_weight`| real    | 🆕 Суммарный вес товаров за интервал (кг)   |
| `avg_weight`  | real    | 🆕 Средний вес товара за интервал (кг)      |
| `load_pct`    | real    | 🆕 Загрузка в процентах (load × 100)        |

### GET /api/report/heatmap
- **Описание:** Генерация тепловой карты загрузки ПВЗ.
- **Доступ:** `@login_required`
- **Вход:** query params (фильтры по дате, ПВЗ).
- **Выход:** 200 OK с телом в формате JSON.
- Пример ответа:
```json
{
  "pvz_id": 1,
  "capacity_per_hour": 50,
  "day_names": ["Пн","Вт","Ср","Чт","Пт","Сб","Вс"],
  "matrix": [
    { "day": 0, "hour": 12, "load_pct": 90.0, "ops": 45 }
  ]
}
```

---

### GET /api/export/csv
- **Описание:** Экспорт данных о загрузке в CSV.
- **Доступ:** `@login_required`
- **Query-параметры:** `date_from`, `date_to`, `pvz_id`, `type`, `region`
- **Выход:** 200 OK — CSV файл (UTF-8 BOM)
- **Колонки CSV:**

| Колонка            | Описание                              |
|--------------------|---------------------------------------|
| `pvz_id`           | Идентификатор ПВЗ                     |
| `address`          | Адрес ПВЗ                             |
| `date`             | Дата                                   |
| `hour`             | Час                                    |
| `ops`              | Количество операций                   |
| `capacity`         | Пропускная способность                |
| `load`             | Коэффициент загрузки                  |
| `total_weight_kg`  | 🆕 Суммарный вес товаров (кг)         |
| `avg_weight_kg`    | 🆕 Средний вес товара (кг)            |

---

### GET /api/errors 🆕 НОВЫЙ
- **Описание:** Журнал ошибок валидации.
- **Доступ:** `@role_required("analyst", "supervisor")` — только аналитик и супервайзер.
- **Query-параметры:** нет (возвращает последние 200 записей)
- **Выход:** 200 OK
```json
[
  {
    "id": 55,
    "pvz_id": 99,
    "ts": "2025-03-10 07:00:00",
    "op_type": "in",
    "reason": "ПВЗ 99 не работает в этот день недели (6)",
    "logged_at": "2025-03-10 10:30:00"
  }
]
```
- **Ошибки:** 403 — доступ запрещён (роль operator)

## Коды ошибок

| Код | Описание                          | Когда возникает                              |
|-----|-----------------------------------|----------------------------------------------|
| 400 | Bad Request                       | Ошибка валидации данных                      |
| 401 | Unauthorized                      | Отсутствует авторизация                      |
| 403 | Forbidden                         | Нет прав на действие (чужой ПВЗ, роль)      |
| 404 | Not Found                         | Ресурс не найден                             |
